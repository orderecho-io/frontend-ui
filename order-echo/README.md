# OrderEcho App

A modern React application for AI-powered restaurant ordering system.

This app was built with Vite+React and provides a beautiful landing page for OrderEcho restaurant ordering solution.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Open your browser and navigate to `http://localhost:5173`

## Features

- Modern, responsive design
- Lead capture form
- Restaurant ordering information
- Mobile-friendly interface

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- Radix UI Components
- Framer Motion

For more information about OrderEcho, please visit our website.
